### 1-3. 규칙
- 에셋에는 텍스트를 넣지 않는다. 글자는 TMP로 올린다.
- 1px 도트로 그리고 정수배로 확대한다. 안티에일리어싱, 블러, 그라디언트는 쓰지 않는다.
- 늘어나는 판은 9-slice로 쓴다. 9-slice 판은 바탕을 단색으로 두고, 질감은 늘어나지 않는 요소에만 넣는다.
- 기존 청록 회로 HUD(좌측 상태 패널)는 이번 범위가 아니다. 리뉴얼 대상 팝업만 갈색 톤으로 통일한다.

- 프로젝트 경로(실제)
  - 설정 팝업: `Assets/Contents/06_UI/Sprites/Settings/`
  - 게임 오버: `Assets/Contents/06_UI/Sprites/GameOver/` (일러스트는 기존 `GameOverPanel.png`에서 잘라낸 `GameOver_Illustration.png`, Bilinear)
  - 전리품 패널: `Assets/Contents/06_UI/LootPanel/` (`LootPanel.png`는 노멀로 덮어씀, 나머지 3장과 `LootPanelSkin.asset` 추가)
  - 도감 책·책갈피: `Assets/Contents/06_UI/Sprites/Diagram/` (덮어쓰기, GUID 유지. 책은 Max Size 4096)
- 공통 임포트 설정
  - Sprite (2D and UI), Single
  - PPU 100
  - Filter Point
  - Compression None
  - Mip Map 끔
- GUID
  - 기존 파일을 같은 역할로 대체하는 경우: 파일명과 `.meta`를 유지하고 png만 덮어쓴다.
  - 새 파일인 경우: 배치모드 에디터 스크립트로 참조를 교체한다.
  - Sprite Mode가 바뀌면 fileID를 21300000으로 재연결한다.

## 5. 적용 절차 (패널 공통)

1. Unity 에디터를 끈다.
2. 에셋을 복사하고 임포트 설정과 9-slice를 적용한다(배치모드 스크립트로 일괄 처리).
3. 배치모드 에디터 스크립트로 프리팹을 수정한다. 스프라이트 교체, 레이아웃, 글자 색이 대상이다.
4. 에디터를 켜서 확인한다. 9-slice 늘어짐, 클릭 영역, 텍스트 넘침, 16:10 비율을 본다.
5. 일회용 스크립트는 검증 후 삭제한다.
6. 커밋한다. 작업 단위별로 나누고 AI 서명은 넣지 않는다.
