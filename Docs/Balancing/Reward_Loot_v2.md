## 1. 왜 바꾸나

| 문제 | 근거 | v2 대응 |
|---|---|---|
| 표가 코드에서 안 쓰인다 | 지금 전리품은 인스펙터 풀에서 등급 없이 뽑는다 | 이번 1차에서 표를 실제로 읽는다 |
| 등급 구간이 스테이지(1~25) 기준이다 | 데모는 3바이옴(전투 약 30회)이라 거의 모든 판이 첫 구간에 머문다 | **바이옴 단계(0~5)** 기준으로 바꾸고, 엘리트 표를 따로 둔다 |
| 티켓 1장이 노멀이다 | 상점 티켓 팩이 300G 다 | 티켓 1장 → 레어, 2장 → 에픽 |
| 골드 보상이 너무 크다 | 노멀 150G = 상점 피규어 1개값, 일반 전투 골드(약 30~40G)의 4배 | 노멀 80 / 레어 160 / 레전드 400, 바이옴 단계 골드 배율 적용 |
| 숲이 쉽다 | 숲 보스 도착 체력 79%(목표 40~55%) | 회복 보상을 낮춤(15→12, 25%→20%, 50%→35%) |
| 없는 스낵이 있다 | `초콜릿`은 `SnackType`에 없다 | 포춘쿠키로 바꿈 |
| 1차에서 못 만드는 효과가 있다 | 스낵칸 확장(UI 5칸 고정), 리필 패시브, 덱 자동 스탬프, 콤보 | `Phase 2`, `Enabled=false`로 표에만 남김 |
| 페퍼민트 등장률 | 지금 스낵 칸 1/7(약 14%) | 노멀 풀에 넣어 약 14% 유지, 에픽에 2개 묶음 추가 |
